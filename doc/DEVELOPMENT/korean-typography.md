# 한글 문서의 강조와 줄바꿈

## 현재 상태

명세가 CommonMark 문법과 GitHub 스타일을 정하고 있어, 한글 문서에서 다음 두 가지가 GitHub와 똑같이 동작합니다.

- **강조**: `**"강조"**는`처럼 닫는 `**` 바로 앞에 문장 부호가, 바로 뒤에 한글이 오면 CommonMark 규칙상 강조가 되지 않고 별표가 그대로 보입니다.
- **줄바꿈**: 긴 문장이 줄 끝에 닿으면 한글 단어 중간에서도 줄이 바뀝니다.

## 해결할 수 있는 방법

- **강조**: 렌더러(comrak)의 CJK 친화 강조 옵션(`cjk_friendly_emphasis`)을 켜면 위 경우에도 강조가 됩니다. 다만 CommonMark·GitHub과 결과가 달라집니다.
- **줄바꿈**: CSS `word-break: keep-all`을 쓰면 한글을 띄어쓰기 단위로만 줄바꿈합니다. 다만 GitHub 스타일과 달라집니다.

## 논의할 점

- 두 가지를 바꿀지 정해야 합니다. 바꾸려면 명세 §4.2를 고치는 명세 요청서가 필요합니다.
