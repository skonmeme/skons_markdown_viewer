# 문서용 실제 화면

## 현재 상태

- ARCHITECTURE.md의 그림은 구조도(SVG)와 자동 여백 애니메이션입니다. 실제 앱 화면을 찍은 이미지는 없습니다.
- 개발용 스냅샷 모드는 요청서 002로 없앴습니다. 이 Mac의 터미널에는 화면 기록 권한이 없어 `screencapture`로도 앱 창을 찍을 수 없었습니다.

## 논의할 점

다음 중 하나로 정해야 합니다.

- 화면 기록 권한을 준 환경에서 `screencapture -l <창 번호>`로 앱 창을 찍어 README와 ARCHITECTURE에 넣습니다.
- 직접 찍은 화면을 받아 넣습니다.
- 실제 화면 없이 지금처럼 둡니다.
