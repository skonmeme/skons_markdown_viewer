# Markdown 확장 기능

## 현재 상태

명세 §4.2가 정한 문법은 CommonMark, GFM 확장(표, 작업 목록, 취소선, 자동 링크), 각주, GitHub 알림입니다. 그 밖의 확장은 지원하지 않습니다.

- **수식**: `$…$`, `$$…$$`, ```` ```math ````는 TeX 원문 그대로 보입니다.
- **Mermaid 등 다이어그램**: ```` ```mermaid ```` 블록은 일반 코드 블록으로 보입니다.
- **목차**: 문서 목차(사이드바)가 없습니다.

## 논의할 점

- 위 기능 중 필요한 것을 정해야 합니다.
- 수식과 Mermaid는 JavaScript 라이브러리(KaTeX, Mermaid 등)를 앱에 넣어야 합니다.
  - 지금은 문서의 JavaScript를 꺼 두었으므로, 앱 전용 스크립트 영역에서 돌리는 방식이 필요합니다.
  - 앱 크기가 커집니다(수 MB).
- 목차는 렌더링 결과의 제목 목록으로 만들 수 있습니다. 창 레이아웃(사이드바)을 명세에 새로 정해야 합니다.
