# 앱 UI 언어

## 현재 상태

- 메뉴, 설정 창, 검색 막대 같은 앱 UI는 영어로만 되어 있습니다(명세 §9.2의 메뉴 표도 영어).
- Help 사용법 문서만 시스템 언어에 따라 한국어·영어로 나뉩니다(명세 §9.2).
- 앱 번들에는 `en.lproj` 하나만 있습니다. 그래서 macOS가 넣어 주는 메뉴(서비스, 윈도우 탭 항목 등)와 열기 패널도 영어로 나옵니다.

## 논의할 점

- 앱 UI를 한국어로도 현지화할지 정해야 합니다.
- `ko.lproj`를 추가하면 시스템이 넣어 주는 메뉴와 패널이 한국어로 바뀝니다. 앱이 직접 만든 메뉴·설정 문자열도 함께 현지화하지 않으면 영어와 한국어가 섞여 보입니다.
- 현지화하려면 명세 요청서로 UI 언어를 명세에 정하고, 모든 문자열을 언어별로 관리하는 방식을 함께 정해야 합니다.
