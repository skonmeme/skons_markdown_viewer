# skon's Markdown Viewer 도움말

## 문서 열기

- Finder에서 Markdown 파일을 이중 클릭하거나 **다음으로 열기 > skon's Markdown Viewer**를 고릅니다.
- 파일을 Dock의 앱 아이콘이나 문서 창에 끌어다 놓습니다.
- **File > Open…**(⌘O) 또는 **File > Open Recent**를 고릅니다.
- 터미널에서는 파일을 앱에 넘깁니다: `/Applications/MarkdownViewer.app/Contents/MacOS/MarkdownViewer README.md`

확장자가 `.md`, `.markdown`, `.mdown`, `.mkd`, `.mkdn`, `.mdwn`, `.mdtxt`, `.mdtext`인 파일을 열 수 있습니다.

파일이 바뀌면 창이 저절로 새 내용을 보여 주고 스크롤 위치는 그대로 유지합니다. 언제든 **File > Reload**(⌘R)로 파일을 다시 읽을 수 있습니다.

## 읽기

- 다른 Markdown 파일로 가는 링크는 이 앱에서, 웹 링크는 브라우저에서 열리고, 제목으로 가는 링크는 그 위치로 스크롤합니다.
- **View > Zoom In**(⌘+), **Zoom Out**(⌘−), **Actual Size**(⌘0)로 모든 창의 글자 크기를 바꿉니다.
- **File > Print…**(⌘P)는 흰 바탕에 검은 글자로 인쇄합니다.
- **Window > Merge All Windows**로 창들을 탭으로 묶을 수 있습니다.

## 검색

- **Edit > Find > Find…**(⌘F)로 검색 막대를 엽니다.
- 입력하는 동안 결과가 나타납니다. 찾은 곳이 모두 강조되고, 현재 위치는 주황색입니다.
- Return이나 ⌘G는 다음, Shift-Return이나 ⇧⌘G는 이전 결과로 갑니다.
- **Match Case**를 켜면 대소문자를 구분합니다.
- ⌘E는 선택한 글자를 지금의 검색 방식으로 검색합니다.
- Esc나 **Done**을 누르면 검색 막대가 닫히고, 현재 결과가 선택된 채로 남습니다.

### 검색 방식

검색 필드 맨 앞에 명령을 입력하고 스페이스를 누르면, 명령이 둥근 표시(토큰)로 바뀌고 검색 방식이 바뀝니다. 토큰 바로 뒤에서 Delete를 누르면 토큰이 지워지고, 남은 글자로 키워드 검색을 합니다. 검색 필드의 지우기 버튼은 토큰과 글자를 모두 지웁니다.

| 명령 | 검색 방식 | 검색 시작 |
|---|---|---|
| 없음 또는 `/key` | 키워드: 입력한 글자를 그대로 찾습니다 | 입력하는 동안 |
| `/match` | 정규식, 대소문자 무시 | Return |
| `/case` | 정규식, 대소문자 구분 | Return |
| `/ai` | AI: 단어가 달라도 뜻이 관련된 부분을 찾습니다 | Return |

- **Match Case**는 키워드 검색에서만 쓸 수 있습니다.
- 정규식은 JavaScript 문법입니다. `^`와 `$`는 문단, 목록 항목 같은 블록의 처음과 끝에 맞습니다. 식이 틀리면 "Invalid pattern"이 보입니다.

### AI 검색

- 예를 들어 `/ai`와 스페이스를 입력하고 "설치 방법"을 쓴 뒤 Return을 누르면, 그 단어가 없어도 설치를 다룬 부분을 찾습니다.
- 결과는 문단, 목록 항목 같은 블록 전체가 강조됩니다.
- 찾는 동안 "Searching…"이 보이고, 긴 문서에서는 "Searching… 2/5"처럼 진행 정도가 함께 보입니다. 찾은 결과는 그때그때 강조됩니다. 질의를 고치거나 검색 막대를 닫으면 멈춥니다.
- 기본 모델은 Mac 안의 Apple Foundation Model이며, 문서가 Mac 밖으로 나가지 않습니다. 시스템 설정에서 Apple Intelligence를 켜야 쓸 수 있습니다. macOS 26에서는 macOS 27보다 느리고 덜 정확합니다.
- 설정의 **AI**에서 외부 LLM을 고를 수도 있습니다.
- "AI unavailable"이 보이면 그 글자 위에 포인터를 올려 이유를 확인하세요.

## 여백

- 기본적으로 여백은 창 폭에 맞춰 바뀝니다. 좁은 창에서는 작고, 넓은 창에서는 넉넉합니다.
- **View > Increase Margins**(⌥⌘+)와 **Decrease Margins**(⌥⌘−)는 여백을 16포인트씩 바꿉니다.
- **View > Automatic Margins**(⌥⌘0)로 자동 여백으로 돌아갑니다.

## 설정

**skon's Markdown Viewer > Settings…**(⌘,)를 고릅니다. 바꾼 내용은 모든 창에 바로 적용되고 저장됩니다.

모든 설정이 한 목록에 있습니다. 사이드바에서 **Fonts**, **Colors**, **Margins**, **AI**를 누르면 그 부분으로 이동하고, 사이드바의 검색 필드에 글자를 쓰면 그 글자가 든 설정만 보입니다.

창의 폭이 700포인트보다 좁으면 사이드바에는 아이콘만 보입니다. 아이콘 위에 포인터를 올리면 이름이 보입니다. 돋보기를 누르면 사이드바가 목록 위로 넓어지고, 검색 필드에 바로 입력할 수 있습니다. 항목을 고르거나, Esc를 누르거나, 사이드바 밖을 누르면 다시 좁아집니다. 검색한 글은 남아 목록을 계속 거르고, 그동안 돋보기가 강조 색으로 보입니다.

- **Fonts**: 글꼴 세트는 영문 글꼴(Latin), 한글 글꼴(Korean), 코드용 고정폭 글꼴(Monospace), 글자 크기, 줄 간격의 묶음입니다. 한글에는 한글 글꼴이, 나머지 글자에는 영문 글꼴이 쓰입니다. Default 세트는 바꿀 수 없으니 **+**로 복사본을 만들어 고치세요. **−**는 세트를 지우고 **Rename…**은 이름을 바꿉니다.
- **Colors**: **Automatic**은 macOS의 라이트·다크 모드를 따르고, **Custom**은 직접 고른 글자색과 배경색을 씁니다.
- **Margins**: **Automatic** 또는 **Fixed**(0–480포인트)를 고릅니다.
- **AI**: AI 검색에 쓸 모델을 고릅니다.
  - **Apple Foundation Model (on this Mac)**: 기본값입니다. 지금 쓸 수 있는지가 아래에 보입니다.
  - **External LLM**: OpenAI 호환 Chat Completions API를 제공하는 서버를 씁니다. AI 검색을 하면 문서의 글과 질의가 그 서버로 보내지므로, 고를 때 확인을 받습니다. 공급자에 따라 요금이 들 수 있습니다.
  - **URL**: 엔드포인트의 전체 주소입니다. 예: `http://localhost:11434/v1/chat/completions`(Mac에서 도는 Ollama), `https://api.openai.com/v1/chat/completions`
  - **Model name**: 서버에서 쓸 모델의 이름입니다.
  - **Model options**: 요청에 더할 키와 값입니다. **+**로 행을 더하고 **−**로 지웁니다. 값이 숫자, `true`, 배열처럼 JSON으로 읽히면 그 값으로, 아니면 문자열로 보냅니다. 예: `temperature`와 `0`
  - **API key**: 서버가 요구할 때만 넣습니다. `*`로 가려지고, 눈 모양 버튼을 누르면 보입니다. 다른 설정과 함께 저장됩니다.
  - **Max tokens**: 모델이 한 번에 읽을 수 있는 토큰 수입니다. 모델의 문맥 창에 맞춰 슬라이더(8K–1M)로 고르거나 직접 입력합니다(1,024–2,000,000). 기본값은 32K입니다.

|---|---|
| 열기 | ⌘O |
| 닫기 | ⌘W |
| 다시 읽기 | ⌘R |
| 인쇄 | ⌘P |
| 검색 | ⌘F |
| 다음 / 이전 결과 | ⌘G / ⇧⌘G |
| 선택한 글자로 검색 | ⌘E |

| 설정 | ⌘, |
| 전체 화면 | ⌃⌘F |
