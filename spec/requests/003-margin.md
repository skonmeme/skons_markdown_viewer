# Margin

## Request

> The original request below is written in Korean and is kept verbatim.

1. 창의 폭에 따라 자동으로 조정되는 여백의 크기를 지금의 반으로 줄여줘.

## Decisions

> 각 결정의 "근거"에는 요청자의 말을 그대로 옮겼다. 요청자가 쓴 "p"는 pt로 읽었다. 폭 `W`와 여백 `M`은 STANDARD §5.1과 같이 페이지(창) 폭과 한쪽 여백이며, 단위는 배율 100 %일 때의 pt다.

원래 요청의 "지금의 반으로"는 D1–D4의 구체 값으로 대신한다. 결과가 모든 폭에서 정확히 지금의 반이 되지는 않는다(Impact의 표).

### D1. 최소 여백은 한쪽 8 pt

- 내용: 자동 여백의 최솟값을 한쪽 16 pt에서 8 pt로 줄인다. 양쪽을 합치면 16 pt다.
- 근거: "최소 마진을 8p" / "8p 최소 마진은 한쪽씩"

### D2. 여백은 폭 480 pt부터 커진다

- 내용: 폭 480 pt까지는 최소 여백 8 pt를 유지하고, 그보다 넓으면 여백이 커진다. 지금은 560 pt부터 커진다.
- 근거: "여백이 커지기 시작한 거는 기존에는 얼마부터?"라는 질문에 Claude가 560 pt라고 답하자 "560p -> 480p로 바꿔줘"

### D3. 폭 1920 pt에서 양쪽 여백의 합은 폭의 15 %

- 내용: 폭 1920 pt에서 양쪽 여백의 합이 288 pt(폭의 15 %), 한쪽 여백이 144 pt다.
- 근거: "창이 커지면 폭 1980까지 최대 15%로 마진이 커지도록 함" / "1920이 맞네"(1980이 1920을 뜻하냐는 질문에 대한 답) / "15%는 양쪽 합쳐서"
- 참고: 1920 pt는 4K(3840 px) 모니터를 2X로 쓸 때의 화면 폭이다(D5의 예).

### D4. 480 pt와 1920 pt 사이에서는 일정하게 커진다

- 내용: 한쪽 여백은 480 pt에서 8 pt, 1920 pt에서 144 pt이고 그 사이에서는 직선으로 커진다. 폭이 1 pt 넓어질 때마다 한쪽 여백이 136/1440 pt(약 0.094 pt) 늘어난다.
- 근거: Claude가 시작 폭 560 pt에서 1920 pt까지 일정하게 늘리는 식 `8 + 0.1 × (W − 560)`을 제시했고, 요청자는 시작 폭만 480 pt로 바꿨다(D2). 직선으로 늘리는 것 자체를 따로 승인한 말은 없다(Open questions 2).

### D5. 폭은 macOS의 포인트로 잰다

- 내용: 폭은 모니터의 실제 픽셀 수가 아니라 macOS가 화면 크기에 쓰는 포인트로 잰다. 2X 화면에서는 3840 px가 1920 pt다.
- 근거: "창 크기 기준은 모니터의 실제 해상도가 아니라 맥 화면 크기. eg. 2X인 경우 3840 -> 1920"
- 효과: 모니터의 픽셀 밀도와 관계없이, 같은 크기로 보이는 창은 같은 여백을 갖는다.
- 지금 STANDARD §5.1도 pt로 재므로 이 결정으로 바뀌는 것은 없다.

## Resulting specification

```
M(W) = 8                               W ≤ 480
M(W) = 8 + 136 × (W − 480) / 1440      480 ≤ W ≤ 1920
M(W) = 미정 (Open questions 1)          W > 1920
```

## Impact

### 사용자에게 보이는 변화

| 폭 `W` | 지금 `M` | 바뀐 `M` | 지금 대비 | 양쪽 여백 / `W` | 지금 본문 폭 | 바뀐 본문 폭 |
|---:|---:|---:|---:|---:|---:|---:|
| 480 | 16 | 8 | 50 % | 3.3 % | 448 | 464 |
| 560 | 16 | 15.6 | 97 % | 5.6 % | 528 | 529 |
| 800 | 100 | 38.2 | 38 % | 9.6 % | 600 | 724 |
| 1024 | 178.4 | 59.4 | 33 % | 11.6 % | 667 | 905 |
| 1440 | 324 | 98.7 | 30 % | 13.7 % | 792 | 1243 |
| 1920 | 492 | 144 | 29 % | 15.0 % | 936 | 1632 |

- 자동 여백은 모든 폭에서 지금보다 작아지고 본문은 넓어진다. 480 pt 이하에서는 정확히 지금의 반이고, 480–654 pt에서는 반보다 크며, 654 pt보다 넓으면 반보다 작다.
- 자동 여백은 설정에 저장된 값이 아니라 공식이므로, 자동 여백을 쓰던 사용자에게는 업데이트하자마자 새 여백이 적용된다. 설정을 옮기는 작업은 필요 없다.
- 고정 여백(§5.2)은 그대로다: 0–480 pt, 폭의 25 % 상한, 16 pt 단위 조절. 다만 View > Increase/Decrease Margins는 지금 보이는 여백에서 시작하므로, 자동 여백 상태에서 처음 누를 때의 시작 값이 작아진다.
- 확대/축소와 인쇄(여백 0)는 그대로다.

## Open questions

1. 폭이 1920 pt보다 넓을 때의 여백. 예를 들어 5K(5120 px) 모니터를 2X로 쓰면 화면 폭이 2560 pt다.
   - (A) 한쪽 144 pt에서 더 커지지 않는다: `M(W) = 144`. 2560 pt에서 양쪽 여백은 폭의 11.25 %다.
   - (B) 양쪽 여백의 합을 폭의 15 %로 유지한다: `M(W) = 0.075 × W`. 2560 pt에서 한쪽 192 pt다.
2. D4처럼 480 pt와 1920 pt 사이를 직선으로 늘릴지.
