# Margin

## Request

> The original request below is written in Korean and is kept verbatim.

1. 창의 폭에 따라 자동으로 조정되는 여백의 크기를 지금의 반으로 줄여줘.

## Decisions

> Details the requester gave later, quoted verbatim. In item 2, "1920이 맞네" is the answer to whether the width 1980 meant 1920. Item 4 changes the width where the margin starts to grow from 560 pt, the value before this request, to 480 pt.

1. 최소 마진을 8p / 8p 최소 마진은 한쪽씩
2. 창이 커지면 폭 1980까지 최대 15%로 마진이 커지도록 함 / 1920이 맞네 / 15%는 양쪽 합쳐서
3. 창 크기 기준은 모니터의 실제 해상도가 아니라 맥 화면 크기.
   eg. 2X인 경우 3840 -> 1920
4. 560p -> 480p로 바꿔줘
